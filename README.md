# Saber-Outline-Glow
A lightweight Outline Glow effect for Effect Craft that adds a customizable, performance-optimized neon border to objects. ✨ Features: • Custom Color &amp; Glow: Tweak radius, thickness, and brightness. • Optimized: High performance on mobile &amp; PC. 🚀 Quick Start: Import the file into Effect Craft and apply it to any texture.
